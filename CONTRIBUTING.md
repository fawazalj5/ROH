# Contributing to the ROH Simulation Platform

We welcome contributions from the community. Please follow these guidelines to contribute.

## Getting Started

1. Fork the repository.
2. Clone your fork: `git clone https://github.com/YourUsername/roh-simulation-platform.git`
3. Create a new branch: `git checkout -b my-feature-branch`

## Making Changes

- Write clean, readable code with comments where necessary.
- Ensure your changes are well-tested.
- Follow the existing code style.

## Submitting a Pull Request

1. Push your changes to your fork: `git push origin my-feature-branch`
2. Open a pull request from your fork to the main repository.
3. Provide a clear description of your changes and why they are needed.
